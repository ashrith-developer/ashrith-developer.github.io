01

Observability · Python

SignalMind

An observability platform that reads a system's traces and metrics, works out the likely root cause of an incident, and proposes a fix — which has to pass a policy check before it runs.

  • A FastAPI analysis service with typed telemetry models and root-cause scoring.
  • A full OpenTelemetry pipeline — Collector into Prometheus, Tempo and Loki, read in Grafana — brought up with Docker Compose.
  • An MCP server that hands incident context and guarded remediation tools to AI agents.
  • LangSmith tracing on every analysis, plus span waterfall and deploy-impact views.

02

Agents · Python

JobFlow AI

An agent that finds job listings and fills out the applications itself — driving a real browser and answering each form's questions from a profile and resume.

  • A LangGraph state machine steering a Playwright browser session, step by step.
  • Gemini writes the answers to application questions using profile and resume context.
  • A web UI streams live logs and a screenshot of every step the agent takes.
  • Containerised with Docker and deployed to Render through GitHub Actions.

03

Forecasting · PyTorch

SAGAR-Net

A graph neural network that forecasts coastal sea levels at twenty tide-gauge stations, from six hours to three days ahead.

  • Combines GESLA tide-gauge records, ERA5 weather reanalysis and GEBCO seabed depth.
  • Dilated causal convolutions read each station's history; GATv2 graph attention lets stations learn from their neighbours.
  • Looks back 72 hours to predict five horizons: 6, 12, 24, 48 and 72 hours.
  • Tested leave-one-station-out, to see how it does at a station it has never seen.

PyTorch · PyTorch Geometric · Pandas · NumPy

Full-stack · JavaScript

AutoMark

A platform for generating marketing content with AI. Sign in, describe what you need, and keep a history of everything you've produced — while Kafka handles the slow work in the background.

  • A React, Vite and Tailwind front end with protected routes and a content history.
  • An Express API on MongoDB, with JWT and Google sign-in.
  • Copy generated through Groq and Google Gemini.
  • Kafka producers and consumers for analytics updates and sign-up notifications.

05

Medical imaging · PyTorch

Alzheimer's MRI Detection

A convolutional network that classifies stages of Alzheimer's from brain MRI slices — built to be honest about its accuracy, and to show its reasoning.

  • Five-fold cross-validation grouped by patient, so no one's scans land in both training and testing.
  • Sampling balanced across classes and patients, with weighted label smoothing.
  • Two-stage fine-tuning, with the best model picked on patient-level macro F1.
  • Grad-CAM heatmaps that show which regions of the brain drove each prediction.

PyTorch · torchvision · scikit-learn · Grad-CAM

Read the code
Splitting by patient, not by slice, keeps the scores honest — otherwise the model is tested on brains it has already seen.
06

Security · Python

LicenseLock

Software licences that can be checked entirely offline — signed by the publisher, verified by the client, and impossible to quietly roll back.

  • Ed25519 signatures over canonical licence bytes, with encrypted PKCS#8 private keys.
  • Checks expiry, product, features and seat count against a trust store.
  • Rollback protection, plus a signed manifest for revoking licences.
  • Strict, grace and local-only policies, available as a CLI and a Python API.
